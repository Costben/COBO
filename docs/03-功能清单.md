# Cobo Web 客户端 — 完成清单

> 最终产物：`com.cobo.app`，应用名 **Cobo**，图标为自绘橙色气泡。
> 基于 `m.weibo.cn` Web API，网页登录一次后复用 Cookie。

## 2. 未支持

| 功能 | 原因 |
| :--- | :--- |
| 视频上传 | Web 端无接口：`statuses/uploadVideo`、`statuses/upload` 均 404；需要原生 gsid + MSS 分片 |
| 收藏 / 取消收藏动作 | `api/favorites/create`、`destroy` 均 404；只能查看收藏列表 |
| 通知的未读角标 | WebView 页面内部状态，未做桥接 |
| 直播 / 超话签到 / 粉丝群 | 未接入对应私有接口 |
| 筛选菜单的「未读微博」 | 仍是空占位。`GET /feed/private` 是悄悄关注流，未接；「悄悄关注 / 本地关注」改为按本机标记拼流后已可用 |

## 3. 关键接口

```text
GET  https://m.weibo.cn/api/config
GET  https://m.weibo.cn/api/container/getIndex?containerid=...
GET  https://m.weibo.cn/statuses/show?id=
GET  https://m.weibo.cn/comments/hotflow?id=&mid=&max_id_type=0
GET  https://m.weibo.cn/api/comments/show?id=&page=
GET  https://m.weibo.cn/message/msglist?page=
GET  https://m.weibo.cn/message/chat?uid=
POST https://m.weibo.cn/api/attitudes/create      id, attitude=heart, st
POST https://m.weibo.cn/api/attitudes/destroy     id, st
POST https://m.weibo.cn/api/comments/create       id, mid, content, st
POST https://m.weibo.cn/api/comments/reply        id, mid, cid, content, st
POST https://m.weibo.cn/comment/like              id, st
POST https://m.weibo.cn/comment/dislike           id, st
POST https://m.weibo.cn/comments/destroy          cid, st
POST https://m.weibo.cn/api/statuses/repost       id, mid, content, st
POST https://m.weibo.cn/api/statuses/update       content, visible=0, st, pic_ids
POST https://m.weibo.cn/api/statuses/uploadPic    multipart: st, pic
GET  https://api.github.com/repos/Costben/COBO/releases?per_page=20   更新检查（独立 OkHttpClient，不带微博 Cookie）
```

评论正文的字段名是 `content`，用 `comment` 会被判为 `100013 参数缺失`。回复楼中楼时 `cid` 传被回复的那条：顶层评论 id 是首条回复，楼中楼里某条回复的 id 则直接嵌在它下面。

请求头：`Cookie`、`Referer: https://m.weibo.cn/`、`X-Requested-With: XMLHttpRequest`、`MWeibo-Pwa: 1`、Web UA。
`st` 同时放表单字段和 `X-XSRF-TOKEN`。

## 4. 代码位置

功能实现集中在 `frontend/`（Kotlin + Compose）：

```
frontend/app/src/main/kotlin/com/cobo/app/
├── data/          # Api、Store、Settings、模型
├── ui/            # 信息流、详情、发布、主页、搜索、消息、设置
└── MainActivity.kt
```

## 5. 说明

- `session.json`、`accounts.json` 含账号凭证，不要提交到仓库。
- Web 接口字段会变，解析全部使用 `opt*` 容错。
